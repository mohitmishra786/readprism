# ReadPrism v0.2.0 (unreleased)

Shared feeds, hosted-mode foundations, a much better first week for new
readers, and many fixes found by new end-to-end tests.

## Before you upgrade

Read [Upgrading: v0.1.0 → v0.2.0](../UPGRADING.md#v010-v020). In short:
a strong `SECRET_KEY` is required, registration is closed by default on
self-host, everyone signs in again (cookie sessions), `GROQ_*` settings are
deprecated, migration 0032 drops the Teams tables, and Meilisearch is no
longer used.

## Highlights

- Shared feeds: a feed followed by many people is polled once (#161).
- Onboarding: starter packs (#152), one-step OPML/Pocket/CSV import (#150,
  #202), your newsletter address with a live test (#151), rating real
  headlines (#149).
- Digest: never empty on quiet days (#142), a faithful "Why" bar (#185),
  emerging topics (#218), "your digest vs newest-first" (#237).
- Interest map: see and edit what ReadPrism learned (#179).
- Search: "Why didn't I see this?" (#267) and real semantic search (#311).
- Weekly "what I learned" email (#184) and gentle win-back (#238), opt-in
  digest alerts by Web Push (#266).
- Offline reading works (#216); readable dark mode (#316).

## Operators

- Backups: retention, row counts, and `make restore-drill` (#209).
- Migrations 0022 to 0037 run on start; see the upgrade guide.
